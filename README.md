# AtlasX · Obsidian

**AtlasX v1.1 — Obsidian build.** Форк [Atlas](https://github.com/Chris12089/atlasbss) для **Bee Swarm Simulator**, адаптированный под **Delta** и большинство современных инжекторов.

> 🐝 Фарм, плантеры, лепестки, блендер, вебхуки, свой UI — всё на месте. Добавлен слой совместимости с исполнителями, чтобы скрипт **запускался и работал**, а не падал с «executor is not supported».

---

## Установка (Delta)

1. Запусти Roblox и зайди в Bee Swarm Simulator.
2. Открой Delta, аттачься к процессу.
3. Вставь содержимое [`loader.lua`](loader.lua) в редактор и нажми **Execute**.

Загрузчик сам скачает актуальную версию, закэширует её и запустит. При повторном запуске сначала пробует сеть, при неудаче — кэш.

### Про прямую ссылку

Открытый адрес в репозитории сознательно не приводится: загрузчик хранит его в закодированном виде. Дай файл `loader.lua` только тому, кому доверяешь — у любого, кто получил файл, ссылку можно восстановить.

Для Delta используй именно загрузчик: он сбрасывает `_G.loading`, уничтожает старое окно и показывает текст ошибки, если что-то не так.

## Что изменено для мульти-инжектора

| Проблема | Как решено |
|---|---|
| Жёсткий выход при `getthreadidentity() < 8` | Проверка стала мягкой: предупреждение вместо `return` |
| `error("Your executor is not supported")` после 5 попыток setup | Setup деградирует в limited mode, скрипт продолжает работу |
| Скрипт перезаписывал рабочий `httprequest` обёрткой поверх `http_request` | Нативный `httprequest` больше не затирается; добавлены алиасы `request` / `http_request` |
| Нет `gethui` / CoreGui только для чтения | `exGuiParent()`: gethui → CoreGui (с проверкой записи) → PlayerGui |
| Нет `fireclickdetector`, `firesignal`, `getconnections`, `setclipboard`, `getcustomasset` | Безопасные заглушки и алиасы (`toclipboard`, `getasset`, `getsynasset`) |
| Нет файловых функций | In-memory fallback: UI работает, конфиг не сохраняется на диск |
| `Out of local registers (limit 200)` | Секция Auto Blender вынесена в `do…end`, очередь через `_G.__atlasGetQueue` (освобождено ~9 регистров) |

Диагностика доступна в игре:

```lua
print(_G.ATLAS_EX)   -- { Name, FileAPI, Http, Hooks, IdentityLevel }
```

## Совместимость

| Инжектор | Статус |
|---|---|
| **Delta** | ✅ Основная цель сборки |
| Wave / VegaX | ✅ Должно работать (тот же набор API) |
| Solara / Xeno | ✅ Базовый фарм, часть hook-функций может быть недоступна |
| AWP / Codex | 🟡 Ожидаемо, тестирование приветствуется |
| Real | ✅ Работает (исходная платформа разработки) |
| Synapse / ScriptWare | 🟡 Legacy, не тестировалось |

Если чего-то не хватает — скрипт не падает, а отключает конкретную функцию. Полный список возможностей смотри в `_G.ATLAS_EX`.

## Возможности

- **Auto Farm** с паттернами Natro, комбо, полями и выбором цели.
- **Petals** — круговые пробежки по бурстам, удержание цели, «уже набранные» цвета по бафф-комбо.
- **Auto Planters / Nectar** — плантеры, нектар, таймеры, выбор разрешённых плантеров.
- **Auto Blender** — очередь рецептов, повтор, тикеты, прогресс и ETA прямо в UI.
- **Auto Quest, RBC, Stickers, Toys, Sprinklers, Converters, Moon/Star Amulet** и остальные вкладки Atlas.
- **Свой UI** с фоном, мобильной кнопкой и сохранением конфига.
- **Вебхуки Discord** — статистика, Honey, графики, уведомления блендера.

## Конфиги

Файлы лежат в папке `atlas/` рабочей директории исполнителя:

- `atlas/Preset 3.json` — активный пресет
- `atlas/default.json` — фабричные дефолты
- `atlas-<ник>.json` — указатель на активный пресет

Сохранение автоматическое при изменении любого контрола. Чтобы применить другой пресет — кнопка **Load Config** (перезагружает скрипт).

## Частые вопросы

**«Limited executor detected»** — у инжектора нет части API. Фарм работает, но hook-функции (кастомные эффекты, часть автоматизаций) могут быть отключены.

**Ошибка `Out of local registers`** — у инжектора жёсткий лимит регистров. В этой сборке секция Auto Blender уже вынесена; если ошибка осталась — отключи лишние вкладки или сообщи issue.

**Не сохраняется конфиг** — проверь, что у исполнителя есть `writefile`/`isfile`. Если нет, `_G.ATLAS_EX.FileAPI == false` и настройки живут только до перезапуска.

**Не работает фон** — нужен `getcustomasset` либо HTTP; иначе картинка просто не подгрузится.
